# Student Tier Tracker

Build an MTSS Student Tracking Dashboard.

Allow users to add student names.

Create a draggable MTSS pyramid with Tier 1, Tier 2, Tier 3.

Students can be dragged into tiers.

Show student counts and percentages.

Save student intervention notes.

Export reports to PDF.
